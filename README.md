# 痒痒鼠解放双手 使用指南

## 一、怎么打开

找到文件夹里的 **yys_auto.exe**，**双击运行**即可。

> 💡 建议右键 →「以管理员身份运行」，部分电脑不这样做可能点不了游戏窗口。
>
> 💡 首次打开稍慢是正常的。

程序启动后会自动弹出一个浏览器窗口，这就是控制面板，所有操作都在这里完成。

**紧急停止**：任何时候按键盘上的 **F12**，所有机器人立刻停。

---

## 二、开始之前的准备工作

### ⚠️ 仅支持 MuMu 模拟器

本工具**只适用于 MuMu 模拟器**（MuMu 安卓模拟器），**不兼容阴阳师 MuMu 专版**。请从官网下载普通版 MuMu 模拟器使用。

### 你需要准备：按钮截图（模板）

程序是靠"看"屏幕来找按钮的，所以你得先告诉它按钮长什么样。

**方法一：用程序自带截图功能（推荐）**

1. 打开游戏，停在要截按钮的画面
2. 切到控制面板，点「模板管理」页签
3. 左侧选一个场景（没有就点「＋新建场景」）
4. 点「📷 截取模板」，程序会截一张全屏图
5. 在弹出的画面上用鼠标框选按钮区域 → 自动保存

- 战斗开始前的按钮 → 存到 **begin**
- 战斗结束后的按钮 → 存到 **end**

> **begin 和 end 截法不一样**：
> - **begin**：只截**按钮本身**，范围越小越好，背景越少越好
> - **end**：截**按钮 + 周围背景**，因为战斗结束画面整体变化大，必须带背景才能稳定识别
>
> | 类型 | 示例 |
> |------|------|
> | begin（只截按钮） | ![begin 示例](templates/chi/begin/QQ20260423-131442.png) |
> | end（按钮+背景）  | ![end 示例](templates/chi/end/QQ20260804-180021.png) |

**方法二：手动导入图片**

1. 自己截好按钮图（建议用截图工具裁剪，存为 .png）
2. 在控制面板点「📁 导入本地」，选你的图片即可

### 按钮截图要注意什么？

- 截**清晰**的按钮部分，不要带太多背景
- 一个按钮可以存多张图（不同角度、不同状态），提高识别率
- 图片格式用 **.png**

### ⚠️ 关键注意事项

截图模板时，**模板内的每一个像素都可能被脚本点击**。如果截图范围覆盖了能弹出二级界面的区域，一旦误触弹窗遮挡画面，会导致后续识别全部失败。

截图时务必避开以下位置：

| 位置 | 风险区域 | 说明 |
|------|----------|------|
| 右上角 | 聊天入口 | 误点会弹出聊天窗口，遮盖大半画面 |
| 左上 / 中间 | 御魂/式神弹出提示 | 悬浮的御魂图标或式神提示，点开会进入详情界面 |
| 左下角 | Buff 状态栏 | 点击图标可能展开状态详情或叠加界面 |

> 总之截图范围尽量精确，只框住目标按钮本身，不要捎带无关的 UI 元素。

---

## 三、开始挂机

1. 打开游戏，停在准备战斗的界面
2. 回到控制面板，确认「控制面板」页签已选中
3. 找到你的 Bot 实例卡片
4. 点击 **▶ 开始** 按钮

程序就开始自动循环了：找 begin 按钮 → 点击 → 等战斗结束 → 找 end 按钮 → 点击 → 下一轮。

---

## 四、控制面板怎么看

### 每个 Bot 卡片的按钮

| 按钮 | 干什么的 |
|------|----------|
| ▶ 开始 | 启动自动挂机 |
| ⏸ 暂停/继续 | 临时停下来 / 恢复 |
| ⏹ 停止 | 结束本轮挂机 |
| 🗑 删除 | 删掉这个 Bot |

### 实时数据解释

| 显示 | 意思 |
|------|------|
| 回合 | 已经打了多少次 |
| 均回合 | 平均每回合花了多久 |
| 战斗 | 平均打一次要多久 |
| 耗时 | 已经挂了多少时间 |
| 预计剩余 | 按当前速度，还要多久打完 |

卡片下方的**散点图**展示最近点击的位置分布，绿色是 begin 按钮，蓝色是 end 按钮。

### 战斗次数

每个 Bot 卡片上可以单独设置「战斗次数」，比如设 10 次，打完就自动停止。

## 五、多开多个号

如果你想同时挂多个游戏窗口，点右上角的「＋ 添加窗口」即可。

每个 Bot 独立配置：
- 独立的游戏窗口
- 独立的场景模板
- 独立的战斗次数

## 六、参数配置（一般不用改）

切换到「⚙ 参数配置」页签可以调整一些高级设置。

### 匹配阈值

默认 **0.75**。

| 情况 | 怎么调 |
|------|--------|
| 按钮经常识别不到 | 调低（如 0.65） |
| 经常点到别的地方 | 调高（如 0.85） |

### 休息设置

| 设置 | 默认 | 说明 |
|------|------|------|
| 每打N把休息 | 50 | 挂多少轮后自动歇一会 |
| ± 浮动 | 10 | 不会每次都刚好 50 把，会随机浮动（更自然） |
| 休息时长 | 30 秒 | 每次歇多久 |
| ± 浮动 | 5 秒 | 休息时间也会随机浮动 |

### 鼠标速度

| 设置 | 默认 | 说明 |
|------|------|------|
| 最小速度 | 2500 | 鼠标移动速度下限，越低越拟人 |
| 最大速度 | 3000 | 鼠标移动速度上限 |

### 其他设置

| 设置 | 默认 | 说明 |
|------|------|------|
| 消抖帧数 | 2 | 识别到按钮后，连续确认几帧才点击。调大减少误触，但反应变慢 |
| 识图缩放 | 0.5 | 截图缩小到一半再识别，加快速度。不建议改 |
| 屏幕区域 | 0~1920 / 0~1080 | 限定截图范围，一般缩小到游戏窗口大小即可 |

## 七、常见问题

### 打开程序没反应？

系统需要 **Edge 浏览器**，Win10 / Win11 自带，不用担心。

### 按钮识别不到？

1. 检查模板是否放对了场景目录
2. 把「匹配阈值」调低一些
3. 多截几张不同状态的按钮图

### 鼠标不动或点不对位置？

- 试试右键以**管理员身份**运行
- 部分游戏需要在显示设置里关掉"硬件加速"

### 杀毒软件报警？

正常现象。程序需要模拟鼠标和监听键盘，安全软件可能误会。添加到信任列表就好。

# 已知问题

> 以下问题当前版本尚未修复，仅作记录。

## 1. 暂停后恢复会清空统计数据显示

**现象**：点击「⏸ 暂停」后再点「继续」，Bot 卡片上的已打次数（回合数）、预计剩余时间、耗时、均回合 / 战斗时长等统计数据被清零/重置。

**影响**：无法通过面板了解真实的累计进度，尤其是设置了「战斗次数」上限的任务，恢复后看不到已完成多少。

**排查方向**：暂停/恢复流程中可能重新初始化了统计变量，或恢复时重建了 Bot 实例导致计数状态丢失，可排查 `scheduler.py` 中暂停与恢复路径对计数状态的处理。

## 2. 程序存在最大存活时间，超时后失去连接

**现象**：程序持续运行一段时间后会失去连接（前端控制面板无响应 / 状态轮询失败），需重启程序才能恢复。

**影响**：长时间挂机场景下无法稳定运行，需要人工干预重启。

**排查方向**：

- Eel / WebSocket 连接超时或内存泄漏
- 日志缓冲区无限增长导致内存耗尽
- 长时间运行后句柄/资源未释放
- gevent 相关的定时器或 keep-alive 机制超时

## 3. 中文路径下模板图无法读取

**现象**：模板图片路径包含中文字符时（如场景名「痴」对应的 `templates/痴/...` 目录），程序无法正常读取模板图，识别失败。

**影响**：场景目录使用中文名时功能异常，只能用英文命名场景规避。

**排查方向**：Windows 下 OpenCV（`cv2.imread`）不支持非 ASCII 路径，可改用 `cv2.imdecode(np.fromfile(path, dtype=np.uint8), flag)` 读取，模板加载与截图保存两处需统一处理。

## 附：分阶段可点击范围缓存 + 随机点击（想法详情）

### 思路

图像识别时，每个阶段识别的是**固定的那几张图**，据此区分当前处于哪个阶段（开始阶段 / 结束阶段）。为两个阶段分别维护一份**可点击范围记录**：

- **开始阶段可点击范围**：这一阶段允许点击的坐标集合
- **结束阶段可点击范围**：这一阶段允许点击的坐标集合

### 流程设计

1. **首次进入某阶段时**：扫描该阶段下的**所有模板**，把每个模板匹配到的位置汇总，存入对应阶段的可点击范围记录
2. **后续再次识别到同一阶段时**：不再重新扫描全部模板，直接从已记录的范围中**随机生成一个坐标**进行点击

### 预期收益

- **减少识别耗时**：缓存命中后无需重复扫描全部模板，循环速度更快
- **天然拟人**：每次点击坐标在范围内随机，避免每次点同一个固定点
- **降低误触集中度**：点击位置发散，不会长期压在某个像素上

### 待确认问题

- 范围缓存的失效时机（切换场景 / 窗口尺寸变化 / 识别失败率升高时是否需要重建）
- 范围内随机时是否需要避开模板边缘（边缘更易误触相邻 UI）
- 多模板命中时如何合并范围权重
